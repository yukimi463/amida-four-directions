# 四方八方阿弥陀籤 · 100面リメイク

静的Webゲーム。Android/iPhone向けタッチ操作、PCキーボード対応。実機テストは未実施。

## 20種類の盤面 × 5ステージ
01–05 はしご / 06–10 ダイヤ / 11–15 五芒星 / 16–20 UFO
21–25 六角形 / 26–30 ハート / 31–35 三角形 / 36–40 ウェーブ
41–45 砂時計 / 46–50 円環 / 51–55 稲妻 / 56–60 花びら
61–65 八角形 / 66–70 矢印 / 71–75 蝶 / 76–80 盾
81–85 歯車 / 86–90 ロケット / 91–95 八芒星 / 96–100 土星

線そのものが各形の輪郭に沿います。番号から矢印に沿って進み、接続線では隣の主線に渡ります。線の交差は乗り換えません。交差する主線は下の線に切れ目を入れて区別します。
図形の上下左右の番号・出口は重ならない位置に配置し、導入線で輪郭につなぎます。

## 仕掛け
- 21面からチェックポイントA、46面からA→B。
- 36面から危険地点「!」。
- 61面からハンマー・岩。ハンマーは拾った挑戦中、繰り返し使用できます。
- 岩は未所持ならその場で経路停止。所持中は壊して通過し、岩が薄くなります。
- 91面以降は岩の障壁が2回。81–100もすべてハンマー必須です。
- 所持品は挑戦ごとに初期化。復活は一度。2回失敗後は同じ面から再挑戦。

## 進行と移行
各5面グループの最初の面は最初から選択でき、残りは順に解放します。
ブラウザ保存キーは amida-four-v1 を継続使用。内容のversion=2がリメイク版。
旧版のクリア番号はlegacyClearedとして保管し、新版のクリア数は0から再集計。
旧版で解放済みの面は引き続き選択可能。旧版の現在ステージも可能な限り維持。
保存は端末・ブラウザごとで、同期しません。

## ファイル
- dist/engine.mjs: 形の輪郭、固定シード盤面、経路・アイテム判定。
- dist/progress.mjs: 新旧セーブ移行・解放。
- dist/app.mjs: SVG描画、経路アニメーション、入力、結果表示。
- dist/index.html, style.css: UI。

## 難度調整・BGM版
- 5面ごとの20種類の形と全100面を維持。盤面内の接続・条件を再生成。
- 入口は序盤2〜4、中盤3〜6、後半5〜7。対応する出口のうち複数が旗になり、灰色×は不正解。
- 同じA/Bを複数経路に配置。Aのいずれか1つ→Bのいずれか1つの順に通過する条件。
- ハンマーも複数経路に配置。全ハンマー面で少なくとも4入口がハンマーを取得し岩を通過可能。その中にも不正解ルートが存在。
- 各条件単独では入口が1つに絞れないように候補集合を組み合わせ、全条件でのみ正解が1つになるよう検証。
- 800×800の盤面と拡大・スクロール操作。番号と出口は上下左右の四辺に分散。
- 本リメイクのセーブversion=2を維持。今回の調整ではクリア記録をリセットしない。
- オリジナル曲『星めぐりの小径』を新規作曲・合成。88 BPM、16小節、約44秒のループ。ベル、アルペジオ、ベース。既存の音源サンプルは不使用。
- BGMは明示的な再生操作で開始。停止、音量設定保存、ページ非表示時の一時停止に対応。
- scripts/create_bgm.py が音源の再生成用スクリプト。dist/audio/starlit-path.mp3 を同梱。
- tests/game.test.mjs に単一ヒントで正解が確定しない検証、tests/music.test.mjs にメディア操作状態の単体テストを追加。
- 実機・ブラウザ上での描画や音声再生の検証は未実施。


## 四辺配置・稲妻の視認性修正
- はしご以外の全ステージで番号と出口を四辺へ分散。4入口以上なら入口集合・出口集合の双方が四辺を使用。
- 主線の輪郭の開始位置も入口に応じてずらし、右側一箇所へ集中しない構成。
- 稲妻(51–55)は薄い多重輪郭を廃止し、同じ幅で平行移動したジグザグ主線に変更。
- 稲妻の主線中央部は、最も密な7本でも垂直距離の下限が68座標単位以上。導入・退出線は外周経由。
- 四辺配置・入口出口の間隔・稲妻中央部の間隔・100面の正解判定・BGM操作の単体検証を実行。
- セーブ形式とBGMを維持。ステージ21と53の線・マーク・端点配置を画像でも点検。実機ブラウザでの確認は未実施。
